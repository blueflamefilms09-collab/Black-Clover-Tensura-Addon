Multiverse of Anime quest pack 1.49.0
================================

This folder is generated by tools/quests/gen_quests.py from tools/quests/spec_quests.py. Do not edit it by hand: edit the spec and
regenerate. Every id is a hash of a stable key, so quest progress survives updates.

What it is: the FTB Quests book for the mod (22 chapters, 339 quests, 3 chapter groups, 10 reward tables).
Install: run  /nusmp quests install  as an operator (it copies this pack into config/ftbquests/quests) and then  /ftbquests reload.
Update:  /nusmp quests update   Remove: /nusmp quests uninstall   Status: /nusmp quests status.
The files: data.snbt, chapter_groups.snbt, chapters/*.snbt, reward_tables/*.snbt, lang/en_us.snbt. This README is documentation and is
not copied into the quest folder.

# Devil canon: where each entry came from (rule 10)

English fandom wikis (blackclover / chainsaw-man / blackbutler / blue-exorcist / tensura / dororo / berserk / fairytail .fandom.com): **blocked** in the build session (HTTP 403 to scripted requests, no fix without disguising the client, which was not done).
Japanese Wikipedia: reachable, not used yet. English Wikipedia: reachable but rate-limited; character lists fetched for Black Clover, Chainsaw Man, Blue Exorcist, Berserk, Fairy Tail. Not fetched: Black Butler, Tensura, Dororo (HTTP 429).

Wikipedia gives each devil's role and powers, almost never its looks. So the looks of every devil are still from the artist's memory of the series and are marked in the per-group docs with a confidence level. Anything a reader knows to be wrong should be sent as a reference image or link.

# Tier List skin remake, group c (big_mom, code, foxy, ao)

Hand-painted skins (`tools/tier_bosses/remake/<id>.py`, helper `lib_c.py`), pixel by pixel, no generic painter. Hair is a kit `anime_*` style, the scalp only is on the base head,
the hat layer top is empty, outfit pieces are on the overlay layers. Previews: `docs/previews/tier_style_v3/c_front_back.png`, `c_close.png`.

**Sources (rule 10):** the English and Japanese wikis (onepiece.fandom.com, naruto.fandom.com, en.wikipedia.org) could NOT be fetched (host not in the session's allowed domains, DNS refused).
All four looks are from memory of the canon designs, bent to the roster sheet in `tier_specs.py`. Nothing was verified against a wiki.

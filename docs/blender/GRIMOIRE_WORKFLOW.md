# Black Clover grimoire in Blender: workflow

Built from the reference set (Black Clover wiki grimoire tables: Clover, Heart and Spade kingdoms and the "Unknown Insignia" books, 33 screenshots).
A working starting point is generated by `tools/blender/build_grimoire.py` (Blender 4.2 LTS - 5.x). Previews: `docs/blender/previews/`.

## 1. What the references say

| Cue | What to model |
|---|---|
| Silhouette | Near-square (about 1 : 1.2), thick boards, chunky rounded spine. Usually **floating open in a V**, spine towards the viewer, covers angled back. |
| Cover layout | Raised **double border frame**; **central medallion** with the kingdom emblem (clover for Clover; suit symbol for Spade / Heart / Diamond); **corner ornaments** (curls, fleur-de-lis). Symmetric. |
| Ornament style | Gold or silver stamped filigree on coloured leather. Spade books darker and harder (Zenon: grey with radial "wheel" medallions and a barred metal spine). Heart books warm with dense gold patterns (Floga, Gadjah). |
| Colour = magic | Cover colour follows the magic: fire red/orange, wind green, water pale blue, dark purple, light gold. |
| Glow | Almost every grimoire glows in its magic colour; pages are bright cream and bloom. |
| Special cases | Four-leaf: gilded frame, four-leaf medallion (Yuno: dark olive + gold). Five-leaf / Asta: black, filthy, tattered, black clover, red-black aura. Julius: fanned, almost coverless page block. Karna: red straps with buckles. |

## 2. Blocking (low poly)

1. `Shift+A > Mesh > Cube`. `S` + `Shift+Y` (scale X/Z), aim for **W 1.0, H 1.22, board 0.065**. `Ctrl+A > Scale` to apply.
2. Duplicate for the page block (`Shift+D`): 0.95 x 1.17, depth 0.10, behind the board.
3. Spine: `Shift+A > Mesh > Cylinder`, 16 verts. `Tab`, delete the back half (`X > Vertices`), add a **Solidify** (thickness 0.05).
4. Hinge: `Shift+A > Empty > Plain Axes` at the spine. Parent the board and pages to it (`Ctrl+P > Object`). Rotate the empty on Z (`R Z 34`) to open the cover.
5. Mirror the half: duplicate the hinge tree and `S X -1`, or keep one half and add a **Mirror** modifier on X (mirror object = the root empty).
6. Silhouette check: `Numpad 0` camera, `Z > Solid`, overlays off, and look at the shape in black (`Shading > Lighting: Flat`, `Color: Single`, black). Fix proportions now, not after detailing.

## 3. Detailing: hard surface for the book, sculpt for the soft bits

The cover is hard-surface, so keep it as modelling plus modifiers. Sculpt only the organic parts (tattered edges, leather wear, characters).

- **Frame:** `Tab`, select the outer face, `I` (inset) 0.07, `I` again 0.06, select the ring between, `E` 0.02 (extrude out). Repeat for the thinner inner frame.
- **Bevels:** a **Bevel** modifier (Limit: Angle 30°, 2-3 segments, 0.015) on every hard part. Hard but slightly rounded edges catch the cel highlight.
- **Medallion:** cylinder (48 verts), depth 0.024, rotated 90° on X. Inset the cap for the inner field.
- **Clover / suit symbol:** draw it as a **Curve** (`Shift+A > Curve > Bezier`): one heart leaf, `Shape > 2D`, `Fill: Both`, `Extrude` 0.008, then duplicate and rotate the leaves (shamrock: 0°, ±115° plus a stem; four-leaf: 4 x 90°; five-leaf: 5 x 72°). `Object > Convert > Mesh` when happy.
- **Corner curls:** a Bezier spiral with `Geometry > Bevel > Depth` 0.008. Mirror it into the four corners with an empty and a Mirror modifier (X and Z).
- **Tattered / worn (Asta, five-leaf):** Subdivision (Simple, 3-4), then a **Displace** modifier with a Clouds texture (strength 0.02). For hand detail, apply them and go to Sculpt Mode (`Ctrl+Tab`):
  - `Shift+R` remesh (voxel 0.005)
  - **Scrape** (`Shift+S` palette) to chip the edges
  - **Crease** (`Shift+C`) for cracks
  - **Draw Sharp** for scratches
  - `Shift` smooths, `Ctrl` inverts
  - **Dyntopo** (`Ctrl+D`) only on the damaged edges
- **Characters (if you go there):** start from a 7.5-head stylised base mesh. Black Clover proportions are a sharp chin, large eyes, spiky hair clumps and long legs. Model hair as separate **curve clumps** or extruded strips, not sculpted fur. Keep **clean quad loops** around the eyes, mouth and joints, because cel shading exposes bad normals immediately. Use sculpting for cloth folds on robes, then retopo (`Shift+Tab` snapping to Face, **Quad Remesher** or **RetopoFlow**) before UVs.

Edge-flow rule for NPR: big flat areas, sharp creases where the shadow line should break, and **Custom Normals** (Data > Normals > `Alt+N` or a Normal Edit / Data Transfer modifier from a smooth proxy) on faces so shadows fall as clean shapes.

## 4. UV unwrap and texturing

- Mark seams (`Ctrl+E > Mark Seam`): around each board's edge, around the frame base, and down the inside of the spine. Unwrap with `U > Unwrap` (angle based). Straighten the cover rectangles (`UV > Follow Active Quads`) so ornaments paint straight.
- Pack with `UV > Pack Islands` (margin 0.005). Give the **front cover the most texel space** (scale its island up), the inner page block the least.
- Texel density: 1024 px per book width for close-ups, 256 for game use. Check with a UV grid (`Image > New > UV Grid`).
- Paint in Texture Paint (`Ctrl+Tab` set to Texture Paint):
  - Flat colours only, no painted lighting: the shader does the light.
  - One **base colour** map plus one **mask** map for trim, grime and stitches (R = trim, G = grime, B = glow). Read it with `Separate Color` in the shader.
- Procedural options (what the script uses):
  - **Wave Texture** (Bands, direction Y, scale 60) for page lines.
  - **Noise** (scale 9, detail 6) into a hard Color Ramp for grime.
  - **Gradient (Spherical)** for the halo.

## 5. Shading: cel / anime material (EEVEE)

**Toon cover** (one per material, the script's `toon_material`):

```
Diffuse BSDF (white) -> Shader to RGB -> Color Ramp [CONSTANT]
                                             0.00  shadow colour   (cover x 0.45, hue shifted toward purple/red)
                                             0.32  base colour
                                             0.86  highlight colour (base x 1.25)
                                          -> Mix (Add) <- Layer Weight.Facing (Blend 0.35) -> Color Ramp [CONSTANT 0.55: black -> rim colour]
                                          -> Emission (strength 1) -> Material Output
```

- **Shader to RGB** is EEVEE only. Cycles needs a different approach: Principled BSDF with a constant-ramp light-path trick, or bake.
- The output goes through **Emission**, so colours stay flat and exact. The Diffuse node only *measures* the light.
- Rim colour is the **magic colour**, which gives the anime backlight on the silhouette.

**Gold / silver trim:** same tree with 3 bands, where the highlight band is near white (1.0, 0.97, 0.88) and the shadow is the gold x 0.55. Optionally add a Principled BSDF (metallic 1, roughness 0.25) mixed at 0.15 for a moving glint.

**Pages:** cream base (1.0, 0.95, 0.80) with Wave Texture page lines (Mix > Multiply). Emission strength 1.2-2, so the pages bloom like in the anime.

**Outline (inverted hull):**
1. On the object, add a second material slot with **Outline**: an Emission in a dark tint of the shadow colour, with **Backface Culling** on.
2. Add a **Solidify** modifier with:
   - Thickness 0.01
   - Offset 1
   - **Flip Normals** on
   - Material Offset 1
3. For ink lines inside the shape instead, use **Line Art** (`Shift+A > Grease Pencil > Scene Line Art`, Crease 140°, thickness 2-3).

**Aura / magic glow:** a plane behind the book with Gradient (Spherical) into a Color Ramp (Ease) as the Mix Shader factor between Transparent and Emission (magic colour, strength 2). Material Settings: Render Method **Blended** (4.2+; `Blend Mode: Alpha Blend` earlier).

## 6. Lighting, colour management and render

- **One Sun** (strength 3.5, angle 3°) from upper front-left. Toon ramps want one dominant light. Fill comes from the world colour (magic colour x 0.06).
- **Colour management:** View Transform **Standard**, Look None. AgX or Filmic will grey out the flat colours.
- **Bloom:** EEVEE Legacy (up to 4.1) has the Bloom checkbox. From 4.2, use the compositor:
  - 4.x: `Render Layers -> Glare (Bloom / Fog Glow, threshold 0.85, size 7) -> Composite`.
  - 5.x: the same in the scene's compositing node group (the script sets this up for both).
- **Camera:** 50 mm, slightly below the book and to the right, small Dutch tilt (book root rotated 6°/-5°/-8°), so it floats.
- **Samples:** EEVEE 32-64, Film Filter 1.0. Enable **Freestyle** only if you are not using inverted hulls (it is slower).
- **Turntable:** keyframe the root empty Z rotation 0 -> 360 over 120 frames (`I` on Rotation), with Linear interpolation (`T > Linear` in the Graph Editor). Add a small Z bob with a **Noise** F-Modifier on Location Z.

## 8. Generator script

```
blender --background --python tools/blender/build_grimoire.py -- --preset yuno --render yuno.png --save yuno.blend
```

- **Presets:** `fuegoleon`, `yuno`, `asta`, `noelle`, `yami`, `julius`.
- **Options:** `--res 1280x960`, `--samples 32`, `--open 34` (degrees per cover).
- **In the GUI:** Scripting tab > Open > Run Script. It clears the current scene first.

Every object is a separate, named, editable mesh with live modifiers (Bevel, Outline), so you can carry on from section 3 directly.

## 9. Into the Minecraft mod

The mod's grimoire is a procedural item model with its own textures (`textures/item/grimoire_book`). The armor models (GeckoLib) come from Blockbench. A Blender grimoire is for renders, promo art and reference. To bring it in game, rebuild it in Blockbench at **16 px per block**: boxes only, no curves, and the ornaments baked into a 64x64 texture.

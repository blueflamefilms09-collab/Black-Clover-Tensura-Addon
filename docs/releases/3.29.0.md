# 3.29.0 — unique effects for the ten Evolution Ultimates

See CHANGELOG.md and `docs/vfx_remake/unique_ultimates.md`. Each of the ten Ultimates of 3.28.0 plays its own signature effect (`ULT_*` shapes); client setting `visual.uniqueUltimates` (default on, `nusmp-ultimates-client.toml`) off plays the generic effects of 3.28.x. New self-test `evolution.ultimatevfx`.

Code: `vfx/client/layer/Ult*Layer.java`, `vfx/UltimateVfxFallback.java`, `vfx/client/UniqueUltimatesConfig.java`, `vfx/client/VfxManager.java#spawnUnguarded`.

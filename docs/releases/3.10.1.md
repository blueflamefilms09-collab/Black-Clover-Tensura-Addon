# 3.10.1: Grimoire Tower and Library Ruins no longer generate

Removed on the owner's request (rule 2 exception): the two biome modifiers that placed the Grimoire Tower and the Library Ruins in the overworld. New chunks no longer get them; everything else (features, loot, wizard) stays registered. Existing built structures stay in old worlds.

- NEW: none. REPLACED: none. REMOVED: 2 biome modifier files. KEPT: all code and data of the structures.
- Worst-case cost: none added; fewer features run per new chunk.
- Not seen in a game.

# 3.32.0 — Smaller jar: packed models + detail limit

SMALLER: the 3,198 big text models (294 MB of text in the source tree) go into the jar as compact packed files (15.3 MB, about 18 MB less jar). The packing is lossless and checked file by file at build time; the loaders read both forms.

SMALLER: the 52 heaviest models are cut to 3000 quads (6000 triangles) in the jar by dropping their smallest quads; lengths, grips, scales, void and halo layers and orbit groups are never touched. Worst: Cardinal Halo Chakram, 27% of its surface.

Switches: `-PpackMeshes=false`, `-PmeshQuadCap=0`. See CHANGELOG.md and `docs/mesh_packing.md`.
Code: `mesh/MeshPack.java`, `MeshText.java`, `MeshCap.java`, `MeshPackMain.java`, `build.gradle`.

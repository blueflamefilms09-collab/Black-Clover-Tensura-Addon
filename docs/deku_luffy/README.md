# Deku and Luffy bosses: design pack (not built yet)

Files: `DEKU_LUFFY_MASTER.md` (the design, read first), `DEKU_LORE.md`, `LUFFY_LORE.md` (wiki notes).
The reference images (65 files, from the Fandom wikis) are kept out of the repo on purpose: they are copyrighted art for modelling reference only and must not ship in the mod.

Status: design only. Nothing here exists in the mod yet (checked: no Luffy / Deku / One For All / Gomu code; all of it is NEW, nothing replaces anything).
Order of work (owner): first finish Goku, Kakashi and Sinbad on the Index-style boss frame (`docs/index_boss_format.md`), then boss keys and teleport items, then these two bosses, their drops and the hidden races.
The seven-form system of section 1.1 (1% floor, 5 s invulnerable transform, full bar per form) is the same idea as Goku's per-form bars (4.97.0) and will reuse that code.
